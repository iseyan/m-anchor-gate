## 料金上界の確認

確認時刻は `pricing-bound.review.json` にUTCで記録しています。[公式モデル資料](https://developers.openai.com/api/docs/models/gpt-5.4-mini)の生成料金は、固定モデル `gpt-5.4-mini-2026-03-17` の通常入力USD 0.75／100万トークン、出力USD 4.50／100万トークンで、現行条件と一致しました。

入力8,192以下・出力2,048以下が成立する場合、生成分は1回USD 0.01536、7回USD 0.10752です。既存の生成予約額USD 0.02／回なら、7回分の予約はUSD 0.14です。

一方、今回確認した[料金表](https://developers.openai.com/api/docs/pricing)、[計数ガイド](https://developers.openai.com/api/docs/guides/token-counting)、[計数API仕様](https://developers.openai.com/api/reference/typescript/resources/responses/subresources/input_tokens/methods/count)からは、計数専用の料金上界を確立できませんでした。一般的なResponsesの料金説明だけから、計数が無料、または生成入力と同じ課金だとは決めません。

計数1回の根拠付き予約上界を `c` ドルとすると、予約枠の条件は次です。

```text
0.14 + 7 × c ≤ 1.00
```

これは予算への収まり方を示す式です。`c` の根拠にはなりません。計数の上界・予約額・合計上界はすべて `null` とし、**計数料金が不明なまま最初の計数を送らない**条件を明記しました。

料金が入力長に依存するなら、8,192以下と判明した後だけでなく、計数結果が上限を超える要求の費用も送信前に扱う必要があります。エラー・タイムアウトの料金も含め、適用される公式条件または提供元のアカウント向け確認が必要です。問い合わせ文案をJSONに残しましたが、送信していません。
