`pricing-check.json` records public rates of $0.75 per million input tokens and $4.50 per million output tokens for the fixed model. Conditional cap arithmetic remains $0.01536 per call and $0.10752 for seven calls, with the inherited $1 budget and $0.02 reservation. Recheck at dispatch; this is not incurred cost, account access verification or a price guarantee. [Official model page](https://developers.openai.com/api/docs/models/gpt-5.4-mini)

`token-budget-method.json` records the documented input-count endpoint, which includes request-formatting tokens. It is not called or adopted here. The frozen form says `maximum_total_api_calls=7`; a count request cannot be added by silently redefining this as generation-only. Adopting that method requires separate revised accounting and implementation. Visible-text tokenization or undocumented padding does not establish a whole-request bound. [Official counting guide](https://developers.openai.com/api/docs/guides/token-counting)

R5 inputs depend on actual saved reads. Initial or mocked input counts cannot certify later live inputs. A resolved method must bind each exact generation-request hash, fixed model, method-record hash and count/bound. No `verified_host_token_bound` record is created and readiness will not be appended to this plan.

`storage-map.json` separates offline artifacts from the future official run. Logical store paths come from the condition form; the absolute root belongs in a separate start record. Comparator stores cannot supply authoritative inputs.

The decision is to prepare the available offline check while leaving the unsupported token bound unresolved. Review is advisory; no new reviewer authority or acceptance criterion is introduced. Specification, frozen conditions and binding, 001–003, Bundle, materials and closed reports remain unchanged.

`package-verification.json` and `checks/` record package checks in the authoring environment separately. They are neither a Windows execution receipt nor a passing exact-validator result for the new code.
